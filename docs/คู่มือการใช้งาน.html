สร้างรุ่น (Batch)

ขั้นบังคับ — ต้องทำก่อนเพิ่มคนพิการ

ระบบแบ่งผู้เข้าร่วมเป็น “รุ่น” ตามปี/รอบการอบรม เพื่อให้ติดตามและออกรายงานแยกแต่ละรุ่นได้

⚠️
ต้องสร้างรุ่นก่อน จึงจะเพิ่มข้อมูลคนพิการได้ เพราะช่อง “รุ่นที่เข้าร่วม” เป็นช่อง บังคับ *

ขั้นตอนเพิ่มรุ่น

ไปที่เมนู “จัดการรุ่น” ด้านซ้าย
กดปุ่ม “+ เพิ่มรุ่น”
กรอก รุ่นที่ (เช่น 1, 2, 3) และ ปี พ.ศ. *
เลือก สถานะ และระบุช่วงวันที่ (ถ้ามี)
กด “บันทึก”

สถานะของรุ่น

กำลังดำเนินการ (ACTIVE) เสร็จสิ้น (COMPLETED)

⭐
รุ่นที่ตั้งสถานะ “กำลังดำเนินการ” จะถูกใช้เป็น รุ่นปัจจุบัน แสดงเด่นบนหน้า Dashboard

เพิ่มข้อมูลคนพิการ

หัวใจของระบบ + อัปโหลดรูปถ่าย

ขั้นตอน

ไปที่เมนู “ข้อมูลคนพิการ” แล้วกด “+ เพิ่มคนพิการ”
อัปโหลดรูปถ่าย 1 นิ้ว (ถ้ามี) — กดที่กรอบรูปด้านบน
กรอกข้อมูลส่วนตัวที่มีเครื่องหมาย * ให้ครบ
กรอกที่อยู่ปัจจุบัน + ข้อมูลติดต่อ (มือถือหรือโทรศัพท์อย่างน้อย 1 ช่อง)
เลือก รุ่นที่เข้าร่วม *
กด “บันทึกข้อมูล”

ช่องที่บังคับกรอก *

ช่องเงื่อนไข
ชื่อ–นามสกุลบังคับ
เลขบัตรประชาชน / บัตรคนพิการบังคับ (13 หลัก)
วันเกิดบังคับ (ต้องเป็นอดีต)
ระดับการศึกษาบังคับ
ประเภทความพิการบังคับ (ตอนเพิ่มใหม่)
จังหวัดบังคับ
มือถือ หรือ โทรศัพท์บ้านบังคับอย่างน้อย 1

บันทึกการอบรม & ทักษะ

ในหน้ารายละเอียดของแต่ละคน (7 แท็บ)

เปิดรายละเอียดคนพิการได้โดยกดปุ่มดู (ไอคอนตา) หรือกดที่ชื่อในตาราง จะพบ 7 แท็บข้อมูล

7 แท็บในหน้ารายละเอียด

แท็บเนื้อหา
ข้อมูลพื้นฐานส่วนตัว ที่อยู่ ความพิการ
การอบรมประวัติหลักสูตร / ฝึกงาน
ประสบการณ์งานประวัติการทำงาน รายได้
ทักษะทักษะพร้อมระดับ
ประเมินทักษะPre/Post + Soft Skills (ดูขั้นที่ 5)
ติดตามผลสถานะงานหลังจบ
สถานประกอบการองค์กรที่ฝึก/ทำงาน

เพิ่มประวัติการอบรม

เปิดรายละเอียดคน → แท็บ “การอบรม” → กด “+ เพิ่ม”
กรอกชื่อหลักสูตร (บังคับ) วันที่ ผลประเมิน แล้วกดบันทึก

รูปแบบการอบรม: TRAIN — อบรม LEARN — เรียนรู้ EARN — ฝึกงาน

เพิ่มทักษะ

แท็บ “ทักษะ” → กด “+ เพิ่ม” → กรอกชื่อทักษะ + เลือกระดับ

ระดับทักษะ: เริ่มต้น ปานกลาง เชี่ยวชาญ

ประเมินทักษะ

Pre-test / Post-test / Soft Skills — แยกตามรุ่น

วัดพัฒนาการก่อน–หลังการอบรม บันทึกในแท็บ “ประเมินทักษะ” ของแต่ละคน

คะแนนที่บันทึก

รายการคะแนนเต็มความหมาย
Pre-test100ทดสอบก่อนอบรม
Post-test100ทดสอบหลังอบรม
Soft Skills (4 ด้าน)5 ต่อด้านทักษะทางสังคม

Soft Skills 4 ด้าน (ด้านละ 0–5)

การสื่อสาร การบริหารเวลา การจูงใจตนเอง การทำงานตามหน้าที่

ขั้นตอน

เปิดรายละเอียดคน → แท็บ “ประเมินทักษะ”
เลือก รุ่น (ค่าเริ่มต้น = รุ่นที่คนนั้นสังกัด)
กรอกคะแนน Pre/Post และ Soft Skills 4 ด้าน
กด “บันทึก” — 1 คน มี 1 ผลประเมินต่อ 1 รุ่น
📈
ระบบจะแสดง พัฒนาการ Pre → Post ให้อัตโนมัติ (เพิ่มขึ้น/ลดลงกี่คะแนน) • กรอกเกินคะแนนเต็มระบบปรับให้อยู่ในช่วงที่ถูกต้องเอง
6

ประสบการณ์งาน & สถานประกอบการ

เชื่อมผู้เข้าร่วมกับองค์กร

ก. เพิ่มประสบการณ์ทำงาน

แท็บ “ประสบการณ์งาน” → กด “+ เพิ่ม”
กรอกชื่อองค์กร เลือกรูปแบบงาน วันที่ รายได้ แล้วบันทึก

รูปแบบงาน: ฝึกงาน จ้างงาน อิสระ

ข. เพิ่มสถานประกอบการ (ทำครั้งเดียว ใช้ร่วมกันได้)

เมนู “สถานประกอบการ” → กด “+ เพิ่มองค์กร”
กรอกชื่อองค์กร (บังคับ) ประเภทธุรกิจ ที่อยู่ ผู้ติดต่อ แล้วบันทึก

ค. ผูกคนพิการกับสถานประกอบการ

เปิดรายละเอียดคน → แท็บ “สถานประกอบการ”
เลือกองค์กรจากรายการ + ระบุบทบาท ช่วงเวลา และเงินสนับสนุน (ถ้ามี)

บทบาท: ฝึกงาน จ้างงาน อื่นๆ

7

ติดตามผล

สถานะหลังจบโครงการ

บันทึกสถานะการทำงานหลังสำเร็จการฝึกงาน เพื่อติดตามความก้าวหน้าของผู้เข้าร่วม

สถานะที่บันทึกได้

มีงานทำ ว่างงาน ศึกษาต่อ

ข้อมูลที่บันทึก

ช่องสำคัญ
วันที่ติดตามบังคับ
สถานะงานบังคับ
ประเภทงาน / รายได้ / ทักษะตรงสาย / ความพึงพอใจ / ปัญหาไม่บังคับ

ขั้นตอน

เปิดรายละเอียดคน → แท็บ “ติดตามผล” → กด “+ เพิ่ม”
กรอกวันที่ + สถานะ แล้วกดบันทึก
🗂️
เมนู “ติดตามผล” ด้านซ้าย รวมการติดตามของทุกคนไว้ในที่เดียว ดูภาพรวมได้ง่าย

ออกรายงาน

ปลายน้ำ — พิมพ์ หรือบันทึกเป็น PDF

ระบบออกรายงานได้ 5 ประเภท เลือกกรองตามรุ่นได้ และพิมพ์/บันทึก PDF ได้ทันที

5 ประเภทรายงาน

#รายงานใช้ทำอะไร
1รายชื่อคนพิการสรุปรายชื่อผู้เข้าร่วม
2แบบสังเกตพฤติกรรมรายบุคคลส่งให้วิทยากรก่อนอบรม
3แบบประเมินรายวิชา (25 คะแนน)ให้วิทยากรกรอกคะแนนรายวิชา
4ใบ Certificateใบรับรองผลการอบรม (1 ใบ/คน)
5รายงานส่งบริษัทสรุปส่งบริษัทสนับสนุน

ขั้นตอน

ไปที่เมนู “ออกรายงาน”
เลือกประเภทรายงาน (5 ปุ่มด้านบน)
เลือก รุ่น ที่ต้องการ (ถ้าต้องการกรองเฉพาะรุ่น)
กรอกข้อมูลตั้งค่า (สำหรับ Certificate / ประเมินรายวิชา / รายงานบริษัท)
เลือกรายชื่อ — หรือกด “เลือกทั้งหมด”
กด “พิมพ์ / บันทึก PDF” มุมขวาบน
ในหน้าต่างพิมพ์ เลือกปลายทางเป็น “Save as PDF”
🖨️
ใบ Certificate ไม่มีตราโลโก้ในไฟล์ เผื่อพื้นที่ไว้ให้ ปั๊มตราโลโก้เอง ภายหลัง

จัดการผู้ใช้งาน

เฉพาะผู้ดูแลระบบ (Admin)

เมนู “จัดการผู้ใช้” เปิดเฉพาะ Admin ใช้เพิ่ม/แก้ไข/เปิด–ปิด บัญชีผู้ใช้

เพิ่มผู้ใช้ใหม่

กด “+ เพิ่มผู้ใช้”
กรอกชื่อ อีเมล รหัสผ่าน และเลือก บทบาท
กด “เพิ่มผู้ใช้”

ข้อควรรู้

  • แก้ไขผู้ใช้: เว้นช่องรหัสผ่านว่างไว้ถ้าไม่ต้องการเปลี่ยน
  • กดที่ป้ายสถานะเพื่อสลับ เปิด/ปิด การใช้งานบัญชี (บัญชีปิดเข้าระบบไม่ได้)
  • ไม่สามารถลบหรือปิดบัญชีของตัวเองได้
  • ควรเปลี่ยนรหัสผ่าน admin1234 หลังเริ่มใช้งาน

รูปแบบวันที่

ทุกวันที่ในระบบใช้รูปแบบ วัน/เดือน/ปี (พ.ศ.) เช่น 30/06/2568 — กรอกเป็นตัวเลข ระบบใส่ “/” ให้เอง

สัญญาณแจ้งเตือนในระบบ

  • แถบเขียว = ทำรายการสำเร็จ (เพิ่ม/แก้/ลบ/บันทึก)
  • แถบแดง = ไม่สำเร็จ หรือกรอกข้อมูลไม่ครบ (จะบอกว่าขาดอะไร)
  • กล่องยืนยันลบ = เด้งถามก่อนลบทุกครั้ง กันลบพลาด
