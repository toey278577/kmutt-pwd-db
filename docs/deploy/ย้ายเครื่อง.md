
## 3. ติดตั้งโปรแกรม


## 4. สร้างฐานข้อมูล

ดูรหัสผ่านฐานข้อมูลเดิมใน `env.txt` (เปิดด้วย Notepad) บรรทัด
`DATABASE_URL=postgresql://kmutt:`**รหัสอยู่ตรงนี้**`@127.0.0.1:5432/kmutt_pwd_db`

```bash
sudo -u postgres psql -c "CREATE USER kmutt WITH PASSWORD 'ใส่รหัสจาก-env';"
sudo -u postgres psql -c "CREATE DATABASE kmutt_pwd_db OWNER kmutt;"
```
สำเร็จ = ขึ้น `CREATE ROLE` แล้วตามด้วย `CREATE DATABASE`

> **ไม่มี env.txt (เครื่องเก่าพัง):** ตั้งรหัสใหม่เองในคำสั่งข้างบน แล้วสร้างไฟล์ `.env` ตามแบบ `backend/.env.example` ในขั้น 5:
> `DATABASE_URL=postgresql://kmutt:รหัสที่ตั้ง@127.0.0.1:5432/kmutt_pwd_db` · `PORT=5000` · `JWT_SECRET=` (เว้นไว้ ระบบสร้างให้เอง)
