# กู้ข้อมูลจากไฟล์สำรอง (ระบบจริง)

ใช้ตอนข้อมูลหาย ถูกลบผิด หรือเพี้ยน แล้วต้องการย้อนกลับไปเป็นข้อมูล **ณ คืนที่สำรองไว้**

- ระบบสำรองให้เองทุกคืนตอนตี 2 เก็บย้อนหลัง 14 วัน ที่ `/opt/kmutt/backend/backups/`
  - `backup-YYYY-MM-DDTHH-mm.json` = ฐานข้อมูลทุกตาราง (เวลาในชื่อไฟล์เป็นเวลา UTC = เวลาไทย −7 ชม.)
  - `photos-YYYY-MM-DD.tar.gz` = ไฟล์รูปถ่ายทั้งหมด
  - `before-reset-*.json` = สำรองอัตโนมัติก่อนกดปุ่มรีเซ็ตระบบ (ถ้าติ๊กเลือกไว้) — กู้ด้วยวิธีเดียวกัน
- วิธีนี้ซ้อมกู้อัตโนมัติอยู่ใน `npm test` (ชุด `api/backup-restore`): สำรอง → ทำข้อมูลพัง → กู้ → ทุกตารางทุกแถวต้องกลับมาเหมือนเดิมเป๊ะ
- ⚠️ การกู้ **แทนที่ข้อมูลทั้งหมด** ด้วยข้อมูลในไฟล์ — สิ่งที่เพิ่ม/แก้หลังเวลาสำรองจะหายไป (รวมประวัติการใช้งานหลังเวลานั้น)

---

## ขั้นตอน (ใช้เวลาประมาณ 5 นาที)

**1. เข้าเซิร์ฟเวอร์** — เปิด PowerShell บนเครื่องที่มีกุญแจ แล้ววาง:
```powershell
ssh -i "$HOME\.ssh\kmutt_vps" root@66.42.63.65
```
สำเร็จ = ขึ้น `root@...:~#`

**2. ดูว่ามีไฟล์สำรองวันไหนบ้าง** แล้วเลือกไฟล์ **ก่อน** วันที่เกิดเรื่อง:
```bash
cd /opt/kmutt/backend
ls -lh backups/
```

**3. สำรองสภาพตอนนี้ไว้ก่อน** (ถ้ากู้ผิดไฟล์ จะย้อนกลับมาจุดนี้ได้):
```bash
node scripts/backup-db.cjs
```
สำเร็จ = บรรทัดท้ายขึ้น `✅ สำรองเสร็จ ... → .../backups/backup-<เวลาตอนนี้>.json` — **จดชื่อไฟล์นี้ไว้**

**4. หยุดเว็บชั่วคราว** (กันคนบันทึกข้อมูลระหว่างกู้):
```bash
systemctl stop kmutt-backend
```
(ระบบเฝ้าดูจะเปิดเว็บกลับเองภายใน 5 นาที — ทำขั้น 5-6 ต่อเลย ใช้ไม่กี่วินาที)

**5. กู้ฐานข้อมูล** — เปลี่ยนชื่อไฟล์เป็นไฟล์ที่เลือกในขั้น 2:
```bash
node scripts/restore-db.cjs backups/backup-2026-10-14T19-00.json --wipe
```
สำเร็จ = ขึ้น `✅ กู้คืนเสร็จ ... แถว` และ **ไม่มี** บรรทัด `⚠️ กู้ไม่ครบ`

**6. กู้รูปถ่าย** — ใช้ไฟล์ photos วันเดียวกัน (ถ้าวันนั้นไม่มี ใช้วันก่อนหน้าที่ใกล้ที่สุด):
```bash
tar -xzf backups/photos-2026-10-15.tar.gz -C /opt/kmutt/backend
```

**7. เปิดเว็บ + ตรวจ:**
```bash
systemctl start kmutt-backend
curl -s https://kmutt-pwd.duckdns.org/api/health
```
สำเร็จ = ขึ้น `{"status":"ok"}` → เปิดเว็บ ล็อกอิน ดูว่าจำนวนคนพิการ / ข้อมูลที่หายกลับมาแล้ว

**8. ออกจากเซิร์ฟเวอร์:** `exit`

---

## ถ้ากู้แล้วไม่ใช่ที่ต้องการ

ทำขั้น 4-7 ซ้ำ โดยในขั้น 5 ใช้ไฟล์ที่จดไว้ในขั้น 3 → ข้อมูลกลับไปเป็นเหมือนก่อนเริ่มกู้

## ข้อควรรู้

- ไม่ใส่ `--wipe` = **เติม** เฉพาะแถวที่ยังไม่มี (แถวที่มีอยู่แล้วไม่ถูกแทนที่) สคริปต์จะเตือน `⚠️ กู้ไม่ครบ` บอกจำนวนที่ข้าม — ใช้ตอนย้ายข้อมูลเข้าฐานใหม่ ไม่ใช่ตอนย้อนข้อมูล
- ไฟล์สำรองอยู่บนเซิร์ฟเวอร์เครื่องเดียวกับระบบ — ถ้าเซิร์ฟเวอร์พังทั้งเครื่องไฟล์สำรองก็หายด้วย (ยังไม่ได้ทำสำรองนอกเครื่อง)
- ไฟล์สำรองมีข้อมูลส่วนบุคคล + รหัสผ่าน (แบบเข้ารหัส) — ห้ามส่งต่อ/อัปโหลดขึ้นที่อื่น
